# 극한 체험! 이상한 키오스크 월드

초등학생이 불친절한 키오스크를 체험하며 배리어프리 설계의 필요성을 배우는 정적 웹앱입니다.
Vercel에서는 별도 경로 `/bias`에 알파코 : 블랙박스 체험 앱도 함께 배포됩니다.

## 체험 구성

- 3초 뒤 사라지는 주문 키오스크
- 콩알 버튼 키오스크
- 외계어 메뉴 키오스크
- 흐릿흐릿 색깔 키오스크
- 소리만 알려주는 번호표 키오스크

각 체험은 `어려운 모드`와 `개선 모드`를 비교할 수 있게 구성되어 있습니다.

## 별도 웹앱

- `/bias`: 카메라 기반 인공지능 얼굴 분석처럼 보이는 알파코 : 블랙박스 편향 체험 시뮬레이터
- `/balance`: 같은 예산에서 지역말 지원에 투자한 기기와 표준어 화면 최적화에 투자한 기기를 비교하는 주문 체험. 흰색 주문기 두 대에서 메뉴 선택, 수량·얼음 옵션, 장바구니, 카드 결제와 영수증까지 체험합니다.

## 로컬 확인

```bash
npm run check
npm run dev
```

브라우저에서 `http://localhost:3100` 또는 `http://localhost:3100/balance`를 열면 됩니다.
로컬 서버는 `vercel.json`의 `/bias`, `/balance` 경로와 `cleanUrls`를 반영합니다. 다른 포트는 `npm run dev -- --port 3101`로 지정합니다.

`/balance`의 왼쪽 기기는 표준어·전라도·경상도·제주도 표현으로 메뉴 분류, 음식 설명, 버튼, 장바구니, 옵션, 결제와 영수증을 전환합니다. 같은 개발비에서 지역말 지원에 투자한 가상 제품으로, 구형 화면과 동작당 0.9~2.1초의 지연, 150ms 단위로 끊기는 스크롤과 멈칫하는 로딩 표시, 3.2초의 결제 대기를 설정했습니다. 오른쪽은 표준어만 지원하며 즉시 반응하고 정상적으로 계산합니다. 두 기기의 메뉴와 단가는 같습니다. 성능 차이는 이 가상 제품의 개발 조건이며 사투리 자체의 특성이 아닙니다.

왼쪽은 비어 있지 않은 장바구니의 2·5·8번째 재계산에서 합계 오류를 재현합니다. 오차는 +1,000원과 −500원을 번갈아 사용하며 개별 메뉴의 가격·수량은 바꾸지 않습니다. 오류가 난 합계는 주문 확인·결제 화면·모의 영수증에도 그대로 이어지고, 다음 장바구니 재계산에서는 정상으로 돌아옵니다. 언어 변경과 확대·복귀는 오류 상태를 유지하며 `처음으로`에서 주문과 오류 순서를 초기화합니다. 이 조건은 왼쪽에서 선택한 언어와 관계없이 동일합니다.

학생 화면에는 수업 헤더·설명·미션·성찰 설문을 표시하지 않습니다. 마이크 인식·실제 결제·서버 전송·브라우저 저장 없이 화면 안에서만 작동하며 새로고침하면 주문이 초기화됩니다. 음식 이름은 이해를 위해 일부 공통 명칭을 유지하고, 지역말 문장은 수업용으로 각색했습니다.

오른쪽은 청록·흰색을 바탕으로 둥근 화면과 메뉴 카드, 필 형태의 분류 버튼, 원형 음식 사진, 사진 장바구니로 구성합니다. 반투명한 유리층과 이중 테두리, 가장자리의 빛 반사와 작은 물방울 표현을 사용하며 음식과 글씨 위에는 장식 효과를 겹치지 않습니다. 상세·주문 확인·결제·영수증에도 같은 스타일을 적용하고, 오른쪽 화면에만 로컬 Pretendard 가변 글꼴을 사용합니다. 왼쪽은 네 개의 언어 버튼을 항상 보여 주는 별도 패널과 두꺼운 구형 구획으로 구성합니다. 지역 표현의 어휘와 버튼·옵션·결제 문구는 [제작 기록](assets/balance/README.md)의 참고 자료를 바탕으로 보강했습니다.

처음에는 두 기기를 함께 보여 줍니다. 한 기기를 누르면 해당 주문 화면이 확대되며, 왼쪽 위 `돌아가기`로 두 기기를 다시 볼 수 있습니다. 이동 중에도 각 기기의 장바구니·언어·진행 상태를 유지합니다. 확대 상태에서는 왼쪽은 2열, 오른쪽은 화면 폭에 따라 2~3열의 큰 메뉴와 터치 버튼을 사용하고, 빈 장바구니는 제목 한 줄만 표시합니다. 메뉴 목록은 화면 안에서 스크롤합니다.

메뉴 이미지 생성 프롬프트와 표현 참고 자료는 [제작 기록](assets/balance/README.md)에 정리했습니다.

## Vercel 배포

정적 HTML/CSS/JS 앱이므로 Vercel에서 GitHub 저장소를 연결하면 바로 배포할 수 있습니다.
`vercel.json`에는 확장자 없는 URL을 위한 `cleanUrls`와 `/bias`, `/balance` rewrite를 포함했습니다.
